# Linux - Lista di Comandi con Commento

## 1. Listing File and Directories ⭐

```bash
ls
```
Lista file e directory nella cartella corrente.

```bash
ls -a
```
Mostra tutti i file, inclusi quelli nascosti.

```bash
ls -la
```
Mostra file, directory e permessi in formato dettagliato.

```bash
mkdir
```
Crea una directory.

```bash
cd
```
Cambia directory.

```bash
pwd
```
Visualizza il percorso completo della directory corrente.

```bash
cp file1 file2
```
Copia un file.

```bash
cp -R
```
Copia directory e contenuti ricorsivamente.

```bash
wc -m file.txt
```
Conta i caratteri presenti nel file.

## 2. File System ⭐

```bash
mount
```
Monta un dispositivo e lo rende accessibile nel filesystem.

```bash
lsblk
```
Mostra partizioni e dispositivi a blocchi.

```bash
df -h
```
Mostra lo spazio disco utilizzato e disponibile.

## Permessi sui file

### Tipi di file

| Simbolo | Tipo |
|----------|------|
| - | File normale |
| d | Directory |
| l | Link simbolico |
| c | Device a caratteri |
| b | Device a blocchi |
| p | FIFO/Pipe |
| s | Socket |

### Categorie utenti

| Simbolo | Categoria | Descrizione |
|----------|------------|-------------|
| u | User | Proprietario |
| g | Group | Gruppo associato |
| o | Others | Altri utenti |
| a | All | Tutti |

### Permessi ottali

| Valore | Permesso |
|---------|-----------|
| 0 | --- |
| 1 | --x |
| 2 | -w- |
| 3 | -wx |
| 4 | r-- |
| 5 | r-x |
| 6 | rw- |
| 7 | rwx |

### Esempi comuni

| Ottale | Simbolico | Significato |
|---------|------------|-------------|
| 777 | rwxrwxrwx | Accesso completo |
| 755 | rwxr-xr-x | Proprietario completo |
| 700 | rwx------ | Solo proprietario |
| 644 | rw-r--r-- | File configurazione |
| 600 | rw------- | File privato |

### Comandi principali

```bash
chmod 755 script.sh
chmod u+x script.sh
chmod g-w file.txt
chown utente file.txt
chgrp gruppo file.txt
```

### Permessi speciali

| Bit | Ottale | Significato |
|-----|---------|-------------|
| SUID | 4xxx | Esegue con privilegi del proprietario |
| SGID | 2xxx | Esegue con privilegi del gruppo |
| Sticky Bit | 1xxx | Solo il proprietario può eliminare i propri file |

Esempi:

```bash
chmod 4755 programma
chmod 2755 directory
chmod 1777 /tmp
```
